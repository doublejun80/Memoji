# 화면 이미지 안내

- `current-ui-1200x800.*`  
  현재 `main`의 코드 구조를 기준으로 만든 화면 재구성이다. 실제 실행 화면을 Capture한 것이 아니라 `App.tsx`, `TopBar.tsx`, `Sidebar.tsx`, `MarkdownEditor.tsx`, `RightPanel.tsx`, Tauri 창 크기를 반영한 구조 이미지다.

- `target-ui-1200x800.*`  
  기본 VDI 창에서의 목표 화면이다.

- `target-ui-1440x900.*`  
  넓은 데스크톱에서의 목표 화면이다.

PNG는 검토·보고용이고 SVG는 수정 가능한 원본이다. 일부 Symbol은 환경 Font에 따라 단순 사각형으로 보일 수 있으며 실제 구현에서는 Lucide Icon을 사용한다.
